# 冒险岛视觉挂机小工具 (maplestory-version-player)

一个**纯视觉**的冒险岛挂机工具：HDMI 采集卡看画面、ESP32-S3 虚拟键盘按按键，
**游戏电脑上不安装任何软件**。

```
游戏电脑(只跑冒险岛,纯净)
   │ HDMI
   └─→ HDMI采集卡 ──USB──→ 大脑机(跑本工具: 看 → 想 → 发指令)
                               │ USB串口
                          ESP32-S3(虚拟键盘固件)
                               │ USB
                               └─→ 游戏电脑(系统看来=一把真键盘)
```

核心能力：

- **见怪自动放技能**：上传怪物截图做模板，画面里出现即按键（支持多模板、阈值调节、运行中热替换）
- **血蓝保护**：框选血条/蓝条区域，低于设定百分比自动按喝药键（实机截图校准，误差 <1%）
- **微动仿真**：随机间隔小幅移动/跳跃，降低机器感；施法后自动安静
- **干跑模式**：串口留空时只识别不按键，无硬件也能调试整条识别链路
- **跨平台**：macOS / Windows / Linux 通吃，整个文件夹拷走即用

## 需要什么准备

### 硬件

| 物品 | 要求 | 参考价 |
|---|---|---|
| HDMI 采集卡 | MS2109 方案、1080p60、UVC 免驱 | ¥50~150 |
| ESP32-S3 开发板 | **必须带原生 USB OTG 引脚**（DevKitC-1 / SuperMini 类） | ¥20~50 |
| USB 数据线 ×2 | 数据线，不是充电线 | — |
| HDMI 线 | 连接游戏电脑和采集卡 | — |

### 软件

- Python 3.9+（大脑机）
- Arduino IDE（只烧录 ESP32 固件时用一次）

### 游戏侧

- 游戏电脑 HDMI 输出设为 **1920×1080**，游戏用**无边框全屏窗口**
- 关闭睡眠 / 锁屏 / 屏保
- 游戏内设好技能键和喝药键（工具里要填一样的）

## 怎么使用

```shell
pip install -r requirements.txt
python main.py
```

首次跑通三步走：

1. **干跑验证**：串口选"(干跑模式)" → 开始 → 确认预览有画面、怪物出现绿框、血蓝百分比正确
2. **烧录固件**：按 `使用手册.md` §四 把 `firmware/esp32s3_hid/esp32s3_hid.ino` 烧进 ESP32-S3（串口发 `TAP:A,100` 应打出字母 a）
3. **实机运行**：串口选 ESP32 端口 → 开始 → 游戏电脑开始真实按键

界面操作细节（上传模板 / 框选血蓝条 / 仿真设置 / 常见问题）见 **[使用手册.md](使用手册.md)**；
设计思路与决策记录见 **[PLAN.md](PLAN.md)**。
